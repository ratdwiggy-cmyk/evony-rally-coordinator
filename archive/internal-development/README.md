# Internal development archive

This folder holds development-process documents from before the first public release: phase-by-
phase build status, an internal production-readiness review, a sandbox test report, and a
changelog for the pre-release review pass. They're kept for historical reference but aren't
required reading to use, deploy, or contribute to this project — start with the root
[`README.md`](../../README.md) instead.

- `DEVELOPMENT_STATUS.md` — phase-by-phase build history.
- `PRODUCTION_REVIEW.md` — the pre-release production-readiness review.
- `TEST_REPORT.md` — manual verification notes from a network-isolated sandbox environment.
- `CHANGELOG_CURRENT.md` — changelog for the review-and-fix pass that preceded the public release.
